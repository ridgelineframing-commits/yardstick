2 · Set Scale

Not set
Most sheets are printed to scale — just pick the sheet's scale (e.g. 1/4"=1') from the drop-down. If a sheet is not to scale, use Calibrate: click two points on a known dimension → type the real length. Points show bright green; drag either endpoint later to fix. Accepts 1010'6"10-6

3 · Tools

✎ Markup & Text ▸
⚡ Auto room-detect (beta — still being tuned)
ft
Doors / windows / plumbing / electric: pick the tool, set the preset (or grab a chip), then click the plan — or drag & drop straight onto it. Edit types & sizes later right in the schedule panel.
Structure: click once to pinpoint, or click-drag along a beam — then type the callout.
Auto-trace: click inside a room — it fills to the walls. Manual room: click corners, dbl-click or Enter to finish. Ceiling height is set per room in its details.
Edit: Select tool → click a shape → drag any square handle. dbl-click an edge = add point · Del = delete.
Shortcuts: R room · D door · W window · E electric · P plumbing · B structure · C comment · X ext wall (Keystone) · S select
